messagesRouter exposes protected getConversations, getOrCreateConversation({otherUserId}), getMessages({conversationId, limit}), and sendMessage({conversationId, content, imageUrl}). It verifies conversation membership server-side and sends with ctx.user.id. The client can map returned conversation rows and message rows into the existing visual model, use tRPC for initial data and send fallback, and use the authenticated Socket.io hook for room updates.
