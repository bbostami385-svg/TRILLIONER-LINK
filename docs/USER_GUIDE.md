# TRILLIONER LINK User Guide

## Marketplace

Open Marketplace to browse active listings and filter them by the categories currently present in the live catalog. Add available products to the cart, review quantities, and provide the requested checkout details. Prices and stock are checked again by the server when the transaction is created, so the checkout result reflects the current listing state.

If you publish products, use the seller management panel to create a listing with a name, category, BDT price, stock quantity, optional image, and description. Select **Edit** on an active listing to change its details, or select **Archive** to remove it from public discovery without deleting its history.

## Human verification

Human verification confirms that an account is operated by a person; it does not replace age or government identity verification. Start the liveness check in Settings, allow camera access, center your face in the guide, and follow each movement prompt in the displayed order. The interface may show face-detection and movement guidance when the browser supports it.

After submission, the recording enters secure review. The account is not marked approved by a browser signal. If a challenge expires or an attempt cannot be completed, start a new challenge and follow the prompts more slowly. Identity/KYC remains a separate process used for monetization and payout eligibility.

## Installing the app

TRILLIONER LINK can be installed from a compatible browser using the browser’s install prompt. Installation creates an app-like launcher experience without requiring immediate publication in an app store; hosting, authentication, and required environment variables still need to be configured for each deployment environment.

## Social and Creator modes

During first-time setup, choose **Social Mode** for a personal profile centered on Follow and Followers, or **Creator Mode** for a video-first profile centered on Subscribe and Subscribers. The selection becomes the default profile experience; it does not remove existing posts, videos, relationships, or account information.

You can change the mode later from Settings. The profile action button, audience label, and statistics update to match the selected experience. Social Mode emphasizes posts, stories, communities, and personal connections. Creator Mode emphasizes videos, Shorts, Live content, playlists, community posts, and creator analytics.

## Levels and leaderboard

Your profile level is calculated from the relevant audience relationship for the selected mode. The profile level badge and progress bar show your current position toward the next threshold. When the server recalculates a higher level, the interface may show a celebration animation and congratulatory message; the badge and progress remain tied to server data.

Use the leaderboard filters to compare Social Mode and Creator Mode rankings separately. A leaderboard is informational and does not change your account mode or relationship counts. Continue publishing responsibly and building genuine audience relationships; artificial engagement should not be used to manipulate rankings.
